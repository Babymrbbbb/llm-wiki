# 05 · lint 巡检：五类检查

## 为什么需要 lint

LLM 编译产物不可完全信任。必须有自动化巡检兜底：锚定是否真实、链接是否可到达、结构是否对称、内容是否冲突。

- 每条引用必须能回溯到 raw 层真实文件

### 2. 死链检查

- `index.md` 中的相对链接必须指向存在的页面 → 真实死链
- 页面「关联页面」段指向不存在页面的链接 = **待聚合占位**（不算死链，单独统计）

### 3. 孤立页检查

entity / concept / synthesis 下未被 index.md 引用的页面 → 孤立页。

### 4. 冲突标记

同一实体/概念被多源引用但内容矛盾 → 冲突（简化版：按标题聚合检测）。

### 5. 死循环检测
