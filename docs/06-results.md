## 经验沉淀

1. **Schema 契约是行为一致性的根**：不注入契约，多批次编译结构必然漂移。
2. **聚合是渐进式的**：高频概念先聚合，长尾概念保留占位，按需补生成，避免一次编译成本爆炸。
3. **lint 的「待聚合占位」不是死链**：区分「真实死链」与「待生成占位」，避免误报淹没真问题。
4. **raw 层零修改是信任基石**：编译链路可推倒重建、可回滚，全靠 raw 层不可变。
5. **自动化聚合是知识库可持续的关键**：`generate_agg_pages.py` + `generate_special_pages.py` 把「聚合页生成」从手工变成自动化，配合知识库每日维护任务，新资料入库后自动完成索引→聚合→联动→lint 闭环。

## 开源边界说明

- **公开的是方法论**：架构、Schema 契约、聚合/增量/lint 设计思路（本文档体系）。
- **不公开的是生产实现**：`build_wiki.py` / `generate_agg_pages.py` / `generate_special_pages.py` 生产版本深度绑定品牌私有知识库（品牌实体词表、内部模型服务、知识库路径），属于品牌独特自研改造，不对外提供可运行源码。
